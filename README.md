# Lincoln-Financial---Team-Charizard
Team Charizard (Lillian, Rohan, Izziy, and Randall)'s  Dental Benefits Selection Agent AI

Our team created an Agent AI that allows employees to discuss dental treatments with it, figuring out what the cost of a treatment will be based off what plan they have or choose to have. With this an employee can safely browse between dental plans to find which one fits them best.
